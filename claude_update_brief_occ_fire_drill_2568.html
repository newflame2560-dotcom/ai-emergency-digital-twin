4. Role & Responsibility Matrix

Roleหน้าที่ตามแผนเดิมแสดงใน Prototype เป็น
Building Technicianรับ FCP, แจ้ง รปภ./DC, ให้ข้อมูลจุดเกิดเหตุAlarm Receiver / AIM Support
หัวหน้า รปภ.สั่งตรวจสอบพื้นที่ สนับสนุนดับเพลิง รับหน่วยงานภายนอกSecurity Lead
รปภ.ตรวจสอบพื้นที่ นำถังดับเพลิง ปิดกั้นพื้นที่ นำทางหน่วยงานภายนอกResponse Team / Perimeter Control
DCประสาน CSSM รายงานสถานการณ์ ประสานตัดไฟ/คืนไฟOperation Communication
CSSMสั่ง IC แจ้งหน่วยงาน ประสาน CCR/BCC สั่ง ECOperation Command Support
SRSM / IMผู้จัดการเหตุการณ์ ตั้ง Command Post สั่งการหลักIncident Manager
Building Tech / AIMผู้ช่วย IM ให้ข้อมูลพื้นที่และสถานการณ์Assistant Incident Manager
ICแจ้งหน่วยงานภายนอก/ภายใน/ผู้บริหารCommunication Controller
ECประสานตัดไฟและคืนไฟEngineering Control
Floor / Muster / Chief Wardenนำอพยพ ตรวจนับคน ตรวจ Log BookEvacuation & Headcount Team
Nurse / EMT / SRCS / Safetyปฐมพยาบาล ตรวจสอบพื้นที่หลังเหตุFirst Aid / Recovery Inspection
External Fire Service / Policeระงับเหตุ ตรวจสอบพื้นที่ เก็บข้อมูลหลักฐานExternal Agency Support

เพิ่ม Scenario Preset ใหม่:
G: OCC Fire Drill 2568 — Storage Room Fire
H: OCC Fire Drill + Casualty
I: OCC Fire Drill + Missing Visitors
J: OCC Fire Drill + Fire Spread & Water Use

เพิ่ม Simulation Logic:
- Smoke Detector Active → Alarm Event
- Building Tech รับ FCP → Under Verification
- รปภ. ยืนยันไฟจริง → Confirmed Fire
- ใช้ถัง 2 ถังแล้วควบคุมไม่ได้ → Trigger General Alarm
- General Alarm → Evacuation ทั้งอาคาร
- ผู้บาดเจ็บ → First Aid Area + EMS Handoff
- ผู้ติดค้าง/สูญหาย → Rescue Task + แจ้ง IM
- เพลิงลุกลามและต้องใช้น้ำ → ต้องยืนยัน Power Isolated ก่อน
- External Fire Service มาถึง → IM แสดงข้อมูลพื้นที่ แผนอาคาร และสถานะการอพยพ
- หลังควบคุมเพลิง → EMT/Safety/Police ตรวจพื้นที่ ก่อนคืนไฟและ Reset FCP

เพิ่ม Panel ใหม่:
- Drill Plan Timeline
- Role & Responsibility Matrix
- Command Post Status
- External Agency Coordination
- Power Isolation Checklist
- Recovery & Return-to-Normal Checklist

เพิ่ม AI AAR Report:
- ความสอดคล้องกับแผนเดิม
- จุดที่ดำเนินการได้ตามเวลา / จุดล่าช้า
- ผู้บาดเจ็บ / ผู้ติดค้าง / ผู้สูญหาย
- การสื่อสารกับหน่วยงานภายนอก
- การตัดไฟและใช้น้ำดับเพลิง
- Recovery และ Corrective Action ตามบทบาท

Safety Guardrails:
- AI เป็น Decision Support เท่านั้น
- ห้ามแนะนำให้พนักงานทั่วไปกลับเข้าไปในพื้นที่อันตราย
- Rescue ต้องทำโดยทีมที่ได้รับมอบหมายหรือหน่วยงานฉุกเฉินภายนอก
- การใช้น้ำดับเพลิงต้องเกิดหลังยืนยันตัดไฟแล้ว
- ก่อนกลับเข้าอาคารต้องตรวจสอบความปลอดภัยและ IM ยกเลิกสถานการณ์

เงื่อนไข UI/UX:
- คงสไตล์เดิม ใช้ภาษาไทยเป็นหลัก
- ใช้ badge สี Completed / Delayed / Pending / Critical
- ทุก Preset กดรันได้ทันที
- ใช้ seeded random ให้ผลเดโมคงที่
- ห้ามลบ Scenario A/B/C เดิม และห้ามลบ casualty/fuel/trapped logic ที่เพิ่มไว้แล้ว
